تنظیمات سیستم و آداپتورها

فهرست مستقیماً از Ollama دریافت می‌شود. ابتدا مدل را با دستور ollama pull نصب کنید.

کلید API قبلی ذخیره شده است؛ برای حفظ آن، این فیلد را خالی بگذارید.

گزینه انتخاب خودکار، مدل رایگان مناسب را در هر درخواست از طرف OpenRouter انتخاب می‌کند.

در حال دریافت فهرست مدل‌ها...

مدل انتخاب‌شده فقط برای Provider فعال استفاده می‌شود؛ تنظیمات Ollama و OpenRouter از هم مستقل‌اند.

در این بخش اسناد PDF و متنی خود را برای پردازش توسط مدل nomic-embed-text بارگذاری خواهید کرد.

ماژول ChromaDB در فاز ۳ به این بخش متصل می‌شود.

اتصال کانکتورهای خارجی (مانند GitHub Token یا جستجوی وب) در این بخش قرار می‌گیرد.

ماژول MCP / Function Calling در فاز ۴ به این بخش متصل می‌شود.
