# Contributing to Local AI Assistant

Thank you for considering contributing to this project!

## Development Workflow

1. **Fork & Clone:** Fork the repository and clone it locally.
2. **Branching:** Create a feature branch from `main` (e.g., `git checkout -b feature/rag-integration`).
3. **Code Style:** Follow standard PEP 8 guidelines for Python code and keep provider/tool modules decoupled.
4. **Testing:** Ensure the FastAPI server starts cleanly and verify both local (Ollama) and cloud (OpenRouter) streaming paths before submitting a Pull Request.
5. **Commit Messages:** Write clear, concise commit messages describing the *why* behind your changes.
